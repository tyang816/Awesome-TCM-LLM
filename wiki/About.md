# About

[Awesome-TCM-LLM](https://github.com/tyang816/Awesome-TCM-LLM) 收集开源中文医疗大模型（中医为主、西医/通用中文医疗为辅）的模型、数据、评测、综述与产业动态。

## 和项目页、综述的关系

| 产物 | 角色 |
| --- | --- |
| `data/catalog.yml` | 唯一条目源 |
| README / README_EN | 面向 GitHub 的发现页（目录、折叠、专栏） |
| 本 Wiki | 面向使用者的说明页（选型、分类、贡献） |
| [项目页](https://tyang816.github.io/projects/tcm/) | 搜索与标签筛选 |
| `survey/` | 学术综述手稿，独立于清单 |

## 范围

- **收：** 中医 LLM / 多模态 / Agent / RAG，以及常被当作底座的中文医疗开源模型；可核验的数据与基准；相关综述与重要产业新闻。
- **慎收：** 无法核验链接的自媒体转载、与中医无实质方法交集的通用 LLM 评测。
- **不替代：** 临床指南、诊疗建议。本仓库是研究资源索引，不是医疗产品。
