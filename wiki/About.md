# About

[Awesome-TCM-LLM](https://github.com/tyang816/Awesome-TCM-LLM) 收集**开源中医模型、数据、论文、专利**，也带一点相关中文医疗资源。

## 和项目页、综述的关系

| 产物 | 角色 |
| --- | --- |
| `data/catalog.yml` | 唯一条目源 |
| README / README_EN | 面向 GitHub 的发现页（目录、折叠、专栏） |
| 本 Wiki | 面向使用者的说明页（选型、分类、贡献） |
| [项目页](https://tyang816.github.io/projects/tcm/) | 搜索与标签筛选 |
| `survey/` | 学术综述手稿，独立于清单 |

## 范围

- **收：** 开源中医模型（含多模态 / Agent / RAG）、可核验的数据与基准、方法论文与综述、与清单相关的公开专利（不限中国），以及重要产业新闻；也收常被当作底座或对照的中文医疗开源模型、数据与评测，以及可核验的闭源中文医疗产品和日韩汉方/韩医公开资源。
- **慎收：** 无法核验链接的自媒体转载、与中医无实质方法交集的通用 LLM 评测。
- **不替代：** 临床指南、诊疗建议。本仓库是研究资源索引，不是医疗产品。

## 许可与贡献
